Question 1 · Scope

What exact folder may the tool read?

Pass: You can name one working folder and an explicit denylist. Journals, family/youth, client, legal, medical, trading, credentials, banking, tax, and uncertain material stay closed.

Leak: The answer is “my vault,” “whatever search finds,” or a broad permission granted for convenience.

Question 2 · Authority

Which note wins when two answers disagree?

Pass: One source is explicitly authoritative, with a visible date or freshness signal. The conflict remains visible until an authorized person resolves it.

Leak: The system averages, guesses, or silently uses whichever note appeared first.

Question 3 · Action

What happens before a tool changes the source?

Pass: The exact target and before state are observed, the action is classified, the result is visibly verified, and an exact rollback exists.

Leak: Technical access is treated as permission, or the tool reports success without checking the visible result.
